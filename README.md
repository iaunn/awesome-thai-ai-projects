├── README.md                   # หน้าแสดงรายการผลงานหลัก

## 🛠️ การใช้งานสคริปต์ (Scripts & Automation)

```bash
# 1. รวม Export ทุกไฟล์ใน data/raw/ ล้างข้อมูลส่วนบุคคล และกรอง Noise
python3 scripts/clean_data.py

# 2. join คอมเมนต์เข้ากับข้อมูลที่คัดสรร ตรวจสอบ Schema แล้วสร้าง projects.json
python3 scripts/build_projects.py

# 3. สร้างไฟล์ README.md ใหม่ตามข้อมูลล่าสุด
python3 scripts/generate_readme.py
```

ทุกขั้นตอนเป็น deterministic — รันซ้ำด้วย input เดิมจะได้ output เดิมเสมอ เมื่อมีไฟล์ Export ใหม่ ให้วางไว้ใน `data/raw/` แล้วรันขั้นตอนที่ 1 ใหม่ สคริปต์จะรวมข้อมูลทุกไฟล์เข้าด้วยกัน (คอมเมนต์ที่ถูกลบไปแล้วจะยังคงอยู่ ส่วนคอมเมนต์ที่ถูกแก้ไขจะใช้เวอร์ชันล่าสุด)

## 🤝 การร่วมสมทบข้อมูล (Contributing)

1. เพิ่มรายการใหม่ลงใน **`data/curated.json`** โดยระบุ `source_id` ให้ตรงกับ `id` ของคอมเมนต์ใน `data/comments_clean.json`
2. รัน `python3 scripts/build_projects.py` — สคริปต์จะตรวจสอบ Schema (ฟิลด์ที่จำเป็น, หมวดหมู่ที่ถูกต้อง, id ซ้ำ) และรายงานลิงก์ที่ยังไม่มีใครคัดสรร
3. รัน `python3 scripts/generate_readme.py` แล้วเปิด Pull Request

> ⚠️ อย่าแก้ `data/projects.json` หรือ `README.md` ด้วยมือ เพราะทั้งสองไฟล์ถูก generate ขึ้นใหม่ทุกครั้งที่รันสคริปต์
